# Brasa & Pão Hamburgueria

Landing page de uma hamburgueria artesanal fictícia em Pinheiros, São Paulo.

## O que tem

- Topo com burger que se monta sozinho, faíscas de brasa e vapor
- Cardápio interativo (burgers, acompanhamentos e bebidas) com carrinho em forma de comanda: retirada ou entrega, com entrega grátis acima de R$ 120
- Seção "Anatomia" em que o burger se desmonta conforme a rolagem
- Linha do tempo do preparo, carrossel de avaliações e rodapé com newsletter
- Responsiva, com tema claro e escuro, e respeita a preferência de "reduzir movimento"

Tudo fica em um único `index.html`, sem dependências nem etapa de build. As ilustrações são SVG desenhado no próprio código.

## Como abrir

Abra o `index.html` no navegador. Para publicar, dá para usar o GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

> O pedido e a newsletter são demonstrativos: nada é enviado e nenhum pagamento é cobrado.
